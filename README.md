# 🛡️ ScamShield

### Detect Suspicious Messages. Recognize Scams. Stay Safe Online.

ScamShield is a web application designed to help users understand common online scams,
recognize suspicious messages, and learn how to protect themselves from online fraud.

The platform provides educational information about different types of scams,
their common warning signs, examples of suspicious messages, and practical safety tips.

The goal of ScamShield is to make online scam awareness easier and more accessible.

---

## ✨ Features

### 📚 Learn About Scams

Explore educational information about eight common types of scams:

- Job Scams
- Banking Scams
- Investment Scams
- Shopping Scams
- OTP Scams
- Romance Scams
- Impersonation Scams
- Lottery & Prize Scams

Each category includes:

- An introduction explaining the scam.
- Common warning signs.
- Examples of suspicious messages.
- Practical safety tips.

The scam details page uses a reusable React component to display
category-specific information dynamically.

## 🚀 Getting Started

Follow these instructions to run the frontend locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd ScamShield
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173
```
